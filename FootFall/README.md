This repository contains the source code and documentation for analyzing footfall data. The project uses Python with libraries such as opencv-python, ultralytics and lap.

## Introduction

This project aims to provide insights into footfall patterns in a retail environment. By analyzing data such as the number of visitors over time, we can identify trends, peak periods, and potential areas for improvement.

## Installation

To run this project, you need to have Python installed on your system. Additionally, you will need to install the required libraries. You can do this using `pip`:

```bash
pip install opencv-python ultralytics lap
```

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/tumstech/foot_fall.git
   cd foot_fall
   ```

2. Run the Jupyter Notebook:
   ```bash
   jupyter notebook foot_fall.ipynb
   ```

3. Follow the instructions in the notebook to load and process the data.

## Data

The project uses a source video located at `car.mp4` and `people.mp4`.
